## D2 – What Cache-Control tells the client – Draft

`Cache-Control: public, max-age=60` means the response may be stored by the browser (and any
shared cache) and reused for 60 seconds without asking the server again. Within those 60 s the
client answers from its own copy and sends nothing. After 60 s the copy is stale: the client
revalidates by sending the ETag in an `If-None-Match` header. If the content has not changed the
server replies **304 Not Modified** with no body and the client keeps using its copy for another
60 s; if it changed, the server sends 200 with the new body and a new ETag.
